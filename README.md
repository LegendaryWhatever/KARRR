# Сайт-резюме Карена Царукяна

Файлы в этой папке:

| Файл | Что это |
|---|---|
| `index.html` | сам сайт |
| `figure.png` | фото, из которого рисуется фигура из символов |
| `og.jpg` | картинка-превью для ссылок в Telegram и соцсетях |
| `.nojekyll` | служебный пустой файл: просит GitHub не обрабатывать сайт, а отдать как есть |

## Как выложить на GitHub Pages

Займёт минут 10. Ничего устанавливать не нужно, всё делается в браузере.

### 1. Аккаунт

Зарегистрируйтесь на https://github.com, если аккаунта ещё нет. Запомните свой логин, например `karents`. От него зависит адрес сайта.

### 2. Репозиторий

1. Справа вверху нажмите **+** → **New repository**.
2. В поле **Repository name** впишите `ЛОГИН.github.io`, подставив свой логин. Например, `karents.github.io`. Тогда сайт будет открываться по короткому адресу `https://karents.github.io`.
   Можно назвать и иначе, например `resume`. Тогда адрес будет `https://karents.github.io/resume/`.
3. Выберите **Public**: на бесплатном тарифе Pages работает только с открытыми репозиториями.
4. Нажмите **Create repository**.

### 3. Загрузка файлов

1. На странице нового репозитория нажмите ссылку **uploading an existing file**. Или **Add file** → **Upload files**.
2. Перетащите в окно **содержимое** этой папки: `index.html`, `figure.png`, `og.jpg`, `.nojekyll`, `README.md`. Перетаскивайте сами файлы, а не папку целиком.
   Файл `.nojekyll` скрытый. На Mac его покажет сочетание `Cmd + Shift + .` в Finder, на Windows — «Вид → Скрытые элементы». Если не получится, сайт заработает и без него.
3. Внизу нажмите **Commit changes**.

### 4. Включение Pages

1. В репозитории откройте **Settings** → в меню слева **Pages**.
2. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
3. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
4. Подождите 1–2 минуты и обновите страницу настроек. Вверху появится строка **Your site is live at …** со ссылкой на сайт.

### 5. Превью для ссылок

Чтобы при отправке ссылки в Telegram появлялась картинка, ей нужен полный адрес.

1. В репозитории откройте `index.html` и нажмите карандаш (**Edit**).
2. Найдите строку:
   ```html
   <meta property="og:image" content="og.jpg">
   ```
3. Замените `og.jpg` на полный адрес картинки, например:
   ```html
   <meta property="og:image" content="https://karents.github.io/og.jpg">
   ```
   Если репозиторий называется не `ЛОГИН.github.io`, а, например, `resume`, адрес будет `https://karents.github.io/resume/og.jpg`.
4. Нажмите **Commit changes**.

Telegram запоминает превью. Если ссылку уже отправляли до исправления, обновите превью через бота **@WebpageBot**: пришлите ему ссылку на сайт.

## Как обновлять сайт

Загрузите новую версию файла тем же способом: **Add file** → **Upload files**, с тем же именем. GitHub заменит старый файл. Изменения появятся на сайте через минуту-две.
Мелкие правки текста удобно делать прямо на GitHub: откройте `index.html`, нажмите карандаш, поправьте и сохраните.

## Что стоит знать

- **Сайт виден всем.** На нём ваши телефон, почта и Telegram.
- **Шрифты** (Handjet и PT Mono) подгружаются из Google Fonts. Если они не загрузятся, браузер покажет похожий системный шрифт.
- **Анимация** работает в браузере сама. Если в системе включено «Уменьшить движение», символы перестают меняться.
- **Тема.** Сайт запоминает выбранную тему в браузере посетителя.
- **Свой домен** (например, `tsarukyan.ru`) можно подключить позже в **Settings → Pages → Custom domain**.
